# Lab Kelas

Kumpulan lab dan simulasi kelas berbasis browser untuk mahasiswa
Politeknik Negeri Sriwijaya. Semuanya satu berkas HTML, berjalan tanpa
internet setelah halaman terbuka, dan menyimpan kemajuan di perangkat
mahasiswa masing-masing.

| Folder | Lab | Mata kuliah |
| --- | --- | --- |
| `copywriting-seo/` | Lab Tiga Engine | Copywriting dan SEO |
| `analitik-prepost/` | Lab Analitik & Pre-Post | Copywriting dan SEO |
| `pemasaran-digital/` | Studio UMKM | Pemasaran Digital |
| `perancangan-web/` | Ruang Rancang | Perancangan Web |
| `kesekretariatan/` | Meja Sekretaris | Kesekretariatan 2 |
| `kewirausahaan/` | Ruang Usaha | Manajemen dan Kewirausahaan |

Halaman `index.html` di akar adalah menu yang menautkan seluruh lab.

## Menambah lab baru

1. Buat folder baru, beri nama berkasnya `index.html`.
2. Buka `index.html` di akar, cari blok `DAFTAR LAB`, salin satu entri
   dan ubah isinya.

## Catatan

Nilai yang diberikan lab ini adalah alat bantu ajar, bukan nilai mata
kuliah dan bukan tiruan algoritma mesin pencari atau model AI mana pun.
